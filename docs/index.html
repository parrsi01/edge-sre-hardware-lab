Hardware boundary

A documented TCP protocol separates device behaviour from the control plane. The simulator can be replaced by an approved Linux host without rewriting the application.

02

Reliability evidence

Health and readiness differ, poll outcomes become metrics, invalid telemetry fails closed, and a controlled fault produces an inspectable incident.

03

Operational interface

The dashboard shows live telemetry, availability and recovery. Prometheus and Grafana expose the underlying evidence.

04

Reproducible delivery

Docker Compose starts the complete stack. CI compiles the C++ component, runs Python tests and validates deployment configuration.
